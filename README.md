# Swipe_Animation

KOReader 软件翻页动画补丁（擦除渐显效果）

为 KOReader 提供流畅的「擦除渐显」（wipe）翻页动画效果，特别适合没有硬件翻页动画支持的设备。

## 升级说明

本版本基于koplugin-swipe-animation/Swipe_Animation.koplugin v4.1修改以适配kindle4非触屏设备。

本版本**不修改、不替换任何 KOReader 核心文件**（不覆盖 `frontend/`，也不改动 `ffi/framebuffer.lua`），因此升级与卸载都只涉及 `patches/` 目录，无需 `restore-files` 还原步骤。

- **从本版本早期构建升级**：直接覆盖 `koreader/patches/` 下同名补丁文件即可。
- **从上游旧版（pre-V4.0，曾替换 `frontend/ui/uimanager.lua` / `ffi/framebuffer.lua`）迁移**：请先用您自己的备份还原被替换的系统文件，或重装 KOReader 清除旧版覆盖，再按「安装方法」复制本版 `patches/` 三文件。
- **清理旧补丁**（如设备上存在以下上游旧文件，建议删除以免冲突）：
  - `1-mtk-swipe-direction.lua`
  - `2-mtk-swipe-direction.lua`
  - `2-swipe-full-refresh-judgment.lua`

## 功能特点

- 翻页动画更流畅、速度更快
- 减少翻页过程中的屏幕抖动
- 可自定义刷新速率
- 支持全方向滑动翻页
- 优化夜间模式体验
- **新增**：MTK 设备支持（Kobo、Kindle 2022 及以上）
- **新增**：支持 PDF、DjVu、CBZ 等固定排版格式的翻页动画
- **新增**：支持自定义横/竖屏的翻页动画延迟时间（毫秒）（可通过 **设置（齿轮图标） -> 手势 -> 翻页 -> 翻页动画设置** 进行微调，免去手动修改 lua 文件的麻烦）
- **新增**：支持自定义刷新模式，UI / Fast 两种模式可选

## Kindle 4 / 非触摸屏适配说明

本仓库是上游 `Swipe_Animation` 的**分支**，在保留其擦除翻页动画效果的基础上，针对 **Kindle 4（D01100，2011 款，无触摸屏、仅靠实体翻页键、600 MHz ARM11 / Pearl 屏）** 及同类低性能非触摸墨水屏设备做了专项适配。与原版的主要差异：

- **不替换系统文件**：原版会整份替换 `frontend/ui/uimanager.lua`；本版改为运行期挂钩 `Screen` 的各 `*Imp` 刷新方法，不改动任何 KOReader 核心文件，避免老设备因版本错配闪退。
- **实体翻页键也能触发动画**：KOReader 默认只在触摸滑动时发出翻页动画事件；本版额外挂钩 `ReaderView:onPageUpdate`，在实体翻页键导致页码变化（前后翻页）时直接置位动画标志，使无触摸的 Kindle 4 用左右翻页键同样获得擦除动画，方向自动跟随所按的键。
- **零拷贝动画引擎（默认）**：不再使用 `bb:copy()` + `blitFrom`，而是直接发送条带刷新，利用 eink 屏“刷新前保持旧页”的特性产生擦除效果，规避 Kindle 4 `canUseCBB=false` 时的逐像素慢路径。
- **传统 einkfb 快速刷新**：为 `ffi/framebuffer_einkfb` 补 `refreshFastImp`，使用 `fx_update_fast` 波形，提升 Pearl 屏动画速度（ioctl 失败自动回退 partial）。
- **动画后整屏定影（消除残影 / 锯齿）**：在 Kindle 4 这类使用 `fx_update_fast` 波形的设备上，条带刷新画质偏低、文字易发虚或锯齿；本版在动画成功后自动补一次整屏 partial 刷新把文字定影干净（选择「UI 刷新」模式时条带已清晰，不触发此额外刷新，速度更优）。
- **设置菜单位置（关键）**：KOReader 在**非触摸设备（Kindle 4）上根本不会注册「翻页」菜单**（该菜单仅在 `Device:isTouchDevice()` 为真时创建），其核心「翻页动画」开关也因此不可见。本版改为：在 **「设置」顶层注入独立的「翻页动画设置」条目**（非触摸设备可见），内部含 **翻页动画 总开关** + 五项可调项（刷新模式 UI/Fast、帧延迟、段数、引擎、einkfb 快速刷新）；**触摸设备**则沿用系统「翻页」菜单内的原生开关，并把五项可调项作为「翻页动画设置」子项挂入。
- **移除「轻度全局刷新」**：其依赖的整屏刷新计数逻辑在本版核心中已删除，保留会变成无效控件，故移除。
- 本版**不修改任何系统文件**，因此**无需 `restore-files` 还原步骤**；升级时直接覆盖 `koreader/patches/` 下的同名文件即可。

> 本版仅随附 `patches/` 三个补丁文件，不含 `frontend/` 覆盖文件（仓库内的 `frontend/ui/upstream-uimanager.lua` 仅为上游参考副本，请勿安装）。

## 安装方法

**重要提醒**：安装前请务必备份 `koreader` 文件夹。

### Kindle / Kobo 设备（Linux版）安装步骤

1. 用 USB 线连接设备到电脑。
2. **先备份** 原有的 `koreader` 文件夹。
3. 将本目录 `patches/` 文件夹内的三个文件**复制并覆盖**到设备上的 `koreader/patches/` 目录（本版**不含 `frontend` 文件夹**，无需复制；这正是与原版“同时复制 frontend + patches”的不同之处）。
   - 常见路径：`D:\.adds\koreader\`
   - **特别说明**：如果您的设备原本就支持原生翻页动画，且您不希望使用本补丁的软件擦除动画，而仅希望为 PDF 文件开启设备原生的硬件级翻页动画，您可以选择**只将 `patches` 文件夹里的 `2-pdf-animation.lua`**复制到设备上的 `koreader/patches/` 目录下即可。
4. 安全弹出设备后重启 KOReader。
5. 开启动画（Kindle 4 默认可用，可跳过）：
   - 本版在 Kindle 4 等非触摸设备上**默认已开启**翻页动画，用实体翻页键翻页即可看到擦除效果，无需手动开启。
   - **注意**：Kindle 4 没有触摸屏，KOReader 的「手势」「翻页」菜单**均不显示**。本版已在 **「设置（齿轮图标）」** 顶层提供 **「翻页动画设置」** 条目，所有开关与调参都在那里（不必、也无法在「手势 → 翻页」里找）。
   - 如需关闭：打开任意书籍 -> 点击顶部菜单 -> **设置（齿轮图标）** -> **翻页动画设置** -> 取消勾选 **「翻页动画」**。
6. 调整延迟等（可选）：
   - 进入 **设置（齿轮图标） -> 翻页动画设置**，可以设置横竖屏的动画段数 / 延时（ms）、刷新模式等，长按选项可查看说明。

### 卸载方法

1. 删除设备 `koreader/patches/` 目录下的以下三个文件即可（本版未替换任何系统文件，无需还原 `frontend`）：
   - `2-pdf-animation.lua`
   - `2-swipe-animation-core.lua`
   - `2-swipe-animation-settings.lua`

## 版本兼容

本版**不捆绑、不替换** `frontend/ui/uimanager.lua`，而是运行期挂钩 KOReader 的刷新接口（`*Imp` 方法），因此对 KOReader 版本更宽容。
动画逻辑基于上游 2026-07 前后的公开 API 实现，建议运行较新的 KOReader 版本。

## 支持设备

- **本版主要目标设备**：Kindle 4（D01100，2011 款，无触摸、实体翻页键）。同为非触摸的传统 Kindle 亦可尝试。
- **上游已充分测试的设备**（本版沿用其逻辑，但未在本机复测）：Kobo 系列，Kindle 系列（包括 KV、KO 和 KPW 系列）及大多数运行 KOReader 的 Linux 墨水屏设备。
- **安卓设备**：因在安卓平台表现不佳，暂不支持。

## 菜单结构

> **Kindle 4 / 非触摸设备**：KOReader 不会显示「手势」「翻页」菜单。本版在「设置」顶层注入以下独立条目：

```
设置（⚙）
└── 翻页动画设置
    ├── ☑ 翻页动画              （开 / 关总开关）
    ├── 翻页动画刷新模式
    │   ├── ○ UI刷新
    │   └── ○ Fast刷新
    ├── 竖屏动画帧延迟：毫秒
    ├── 横屏动画帧延迟：毫秒
    ├── 竖屏动画段数：条
    ├── 横屏动画段数：条
    ├── 动画引擎
    │   ├── ○ 零拷贝（推荐）
    │   └── ○ 缓冲（较慢）
    └── ☑ 使用 einkfb 快速刷新（仅传统 Kindle 显示）
```

> **触摸设备**：总开关位于 `设置 → 翻页 → 翻页动画`；五项可调项位于 `设置 → 翻页 → 翻页动画设置`。
## 常见问题
**Q：KOreader安装补丁后闪退怎么办？** 

A：请先使用备份恢复原始文件。常见原因包括：
1. *KOReader 版本过旧。* 请先将 KOReader 更新至最新版本，然后重新安装本补丁。
2. *使用 macOS 复制文件。* 请先恢复原始文件，再手动删除设备中对应的原文件，然后重新复制补丁中的新文件。
3. *安装步骤有误。* 请恢复备份后，按照安装说明重新安装本补丁。

**Q：没有出现“翻页动画”选项？/出现“翻页动画”选项但没有效果？**  

A：1. 请确认在**书籍页面**操作。2. **Kindle 4 等非触摸设备没有「手势」「翻页」菜单**（这些菜单仅在触摸设备显示，核心「翻页动画」开关因此也不可见）。本版已在 **设置 → 翻页动画设置** 顶层提供「翻页动画」总开关与全部调参；触摸设备则在 **设置 → 翻页 → 翻页动画**。3. **Kindle 4 上本版默认已开启**，只要把 `patches/` 三个文件复制到 `koreader/patches/` 并重启，用实体翻页键翻页就应看到擦除动画；若仍无效果，请先更新 KOReader 到较新版本再重试。

**Q：每翻一页都黑白闪烁？**  

A：在 **设置 -> 屏幕 -> 墨水屏设置 -> 完全刷新速率** 中调整数值。
